## 🧪 Security Learning Methodology

I prefer learning security by understanding the full vulnerability lifecycle:

```text
Create a controlled vulnerable application
              ↓
Identify the attack surface
              ↓
Test manually
              ↓
Understand why the vulnerability exists
              ↓
Automate part of the analysis
              ↓
Remediate the vulnerability
              ↓
Retest the same scenario
```

All security labs and testing projects are developed for **owned or explicitly authorized environments**.
